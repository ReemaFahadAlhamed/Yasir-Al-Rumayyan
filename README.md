# Yasir Al-Rumayyan Portfolio Website

A responsive personal portfolio website showcasing Yasir Al-Rumayyan, developed as a group project for our Web Programming course.

## Live Site

[View the live website](https://reemafahadalhamed.github.io/Yasir-Al-Rumayyan/)

## About the Project

This project is a fully responsive, interactive personal portfolio website built with HTML, CSS, and JavaScript. It introduces Yasir Al-Rumayyan, a prominent Saudi businessman, and highlights his career, achievements, and leadership roles.

## Pages

- **Home** – Introduces Yasir Al-Rumayyan with a brief bio and key highlights
- **About** – Detailed information about his career, achievements, and leadership roles
- **Projects** – His major business ventures and contributions
- **Contact** – A functional form for visitors to send messages

## Built With

- HTML5
- CSS3
- JavaScript
- Hosted with GitHub Pages
